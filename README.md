# AI Agent Portfolio

A recruiter-friendly overview of my work and learning around AI agents, workflow automation, and practical LLM systems.

## Why this repo exists

Recruiters often need a quick signal: can this person understand AI agents beyond buzzwords and explain practical use cases clearly? This repository is built to show that signal.

## Focus areas

- AI agent workflows and task decomposition
- Prompt design and evaluation
- Human-in-the-loop automation
- Tool-use agents for research, email, GitHub, and productivity
- Safety, verification, and responsible automation

## Example agent workflows

### 1. Research assistant agent

Goal: collect sources, summarize evidence, and produce a decision-ready brief.

Typical flow:

1. Understand the question
2. Search trusted sources
3. Extract useful facts
4. Compare conflicting information
5. Produce a short recommendation with confidence level

### 2. Job search assistant agent

Goal: find suitable remote roles, evaluate fit, and draft tailored applications.

Useful for:

- AI evaluator roles
- Turkish localization / language quality roles
- Junior AI operations roles
- SaaS/product support roles

### 3. GitHub portfolio assistant agent

Goal: improve public GitHub presentation for recruiters.

Tasks:

- Create clear READMEs
- Add project explanations
- Organize topics and descriptions
- Avoid overclaiming skills
- Highlight learning progress honestly
